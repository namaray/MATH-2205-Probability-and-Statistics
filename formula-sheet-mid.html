UNIT 03 Measures of Central Tendency
📐 Arithmetic Mean
Population \[\mu = \frac{\sum x_i}{N}\]
Sample \[\bar{x} = \frac{\sum x_i}{n}\]
\(\mu\) = population mean \(\bar{x}\) = sample mean \(N\) = population size \(n\) = sample size
Simply: add up all values, divide by how many.
⚖️ Weighted Mean
\[\bar{x}_w = \frac{\sum w_i x_i}{\sum w_i}\]

\(w_i\) = weight of each value · \(x_i\) = data value

Multiply each value by its weight, sum up, divide by total weight.
📈 Geometric Mean
Simple Form \[GM = \sqrt[n]{x_1 \cdot x_2 \cdots x_n}\]
Product Form \[GM = \left(\prod_{i=1}^{n} x_i\right)^{1/n}\]
Multiply all \(n\) values together, take the \(n\)th root.
Use for: growth rates, compound interest, stock returns
🔄 Harmonic Mean
General \[HM = \frac{n}{\displaystyle\sum_{i=1}^{n}\frac{1}{x_i}}\]
Two values \[HM = \frac{2}{\dfrac{1}{a}+\dfrac{1}{b}} = \frac{2ab}{a+b}\]
Divide \(n\) by the sum of reciprocals.
Use for: average speed (same distance, diff. speeds), rates & ratios
📊 Median
Odd \(n\) \[\text{Median} = x_{\left(\frac{n+1}{2}\right)}\]
Even \(n\) \[\text{Median} = \frac{x_{(n/2)} + x_{(n/2)+1}}{2}\]
Sort values → pick the middle one (or average of two middles).
Grouped Data \[\text{Median} = L + \frac{\frac{n}{2} - F}{f} \times h\]
\(L\) = lower boundary \(F\) = cum. freq before \(f\) = freq of median class \(h\) = class width

💡 Median class → where cumulative freq first ≥ \(n/2\)

🏆 Mode

The value that appears most frequently. Can be unimodal, bimodal, multimodal, or no mode.

Grouped Data \[\text{Mode} = L + \frac{f_1 - f_0}{2f_1 - f_0 - f_2} \times h\]
\(L\) = lower boundary \(f_1\) = modal class freq \(f_0\) = class before \(f_2\) = class after \(h\) = class width

💡 Modal class → class with the highest frequency

UNIT 04 Measures of Dispersion
↔️ Range
\[R = X_{\max} - X_{\min}\]

⚠️ Uses only 2 values — badly distorted by one extreme observation.

📏 Mean Absolute Deviation
\[MAD = \frac{\sum |X_i - \bar{X}|}{n}\]

The \(|\cdot|\) is essential — otherwise \(\sum(X_i-\bar{X}) = 0\).

📦 Quartiles, Deciles & Percentiles
Quartile \[Q_k = \left(\frac{k(n+1)}{4}\right)^{\text{th}}\]
Decile \[D_k = \left(\frac{k(n+1)}{10}\right)^{\text{th}}\]
Percentile \[P_k = \left(\frac{k(n+1)}{100}\right)^{\text{th}}\]
Interquartile Range & Quartile Deviation \[IQR = Q_3 - Q_1 \qquad QD = \tfrac{1}{2}IQR\]

💡 \(Q_1 = P_{25}\) · \(Q_2 = D_5 = P_{50} = \) Median · \(Q_3 = P_{75}\) · \(D_k = P_{10k}\)

IQR = spread of the middle 50% of the data.
📐 Variance & Standard Deviation
Population \[\sigma^2 = \frac{\sum (x-\mu)^2}{N} \qquad \sigma = \sqrt{\sigma^2}\]
Sample \[s^2 = \frac{\sum (x-\bar{x})^2}{n-1} \qquad s = \sqrt{s^2}\]
⚡ Short-cut (computational) form \[\sigma^2 = \frac{\sum X^2}{N} - \mu^2\]

💡 Variance = mean of squares − square of the mean. Far faster in exams.

\(N\) = population size \(n\) = sample size \(n-1\) = degrees of freedom (unbiased)
⚖️ Coefficient of Variation
\[CV = \frac{\sigma}{\mu} \times 100\%\]
Unit-free — higher CV = more variable relative to its mean.
Use for: comparing spread across datasets with different units or very different means (risk vs. return, inflation, GDP growth)
5️⃣ Five-Number Summary
① Min ② Q₁ ③ Median ④ Q₃ ⑤ Max

Drawn as a box-and-whisker plot — box spans Q₁→Q₃, line = median.

🎯 Outlier Fences (1.5 × IQR)
\[\text{Lower} = Q_1 - 1.5\,IQR\] \[\text{Upper} = Q_3 + 1.5\,IQR\]

💡 \(x\) is an outlier if \(x < Q_1 - 1.5(Q_3-Q_1)\) or \(x > Q_3 + 1.5(Q_3-Q_1)\)

UNIT 05 Moments, Skewness & Kurtosis
🌀 Moments
Raw moment — about A \[\mu_r' = \frac{\sum (x - A)^r}{n}\]
Central moment — about the mean \[\mu_r = \frac{\sum (x - \bar{x})^r}{n}\]
The first four central moments
MomentValueDescribes
\(\mu_1\)\(= 0\) alwaysDeviations cancel
\(\mu_2\)\(= \sigma^2\)Dispersion / spread
\(\mu_3\)\(\frac{\sum(x-\bar{x})^3}{n}\)Skewness / asymmetry
\(\mu_4\)\(\frac{\sum(x-\bar{x})^4}{n}\)Kurtosis / peakedness

💡 1st raw moment = Mean · 2nd central = Variance · 3rd = Skewness · 4th = Kurtosis

↗️ Skewness \(\beta_1\)
\[\beta_1 = \frac{\mu_3}{\sigma^3}\]
\(\beta_1 = 0\)Symmetrical
\(\beta_1 > 0\)Positively skewed (right tail)
\(\beta_1 < 0\)Negatively skewed (left tail)

💡 Pearson: \(Sk = \frac{\text{Mean}-\text{Mode}}{\sigma} = \frac{3(\text{Mean}-\text{Median})}{\sigma}\)

🔺 Kurtosis \(\beta_2\)
\[\beta_2 = \frac{\mu_4}{\mu_2^{\,2}}\]
\(\beta_2 = 3\)Mesokurtic (normal)
\(\beta_2 > 3\)Leptokurtic (sharp peak)
\(\beta_2 < 3\)Platykurtic (flat peak)

💡 \(\mu_2 = \sigma^2\), so \(\beta_2 = \mu_4/\sigma^4\)

📊 Skewness at a Glance
ShapeTailRelationship
Positive skewRightMean > Median > Mode
SymmetricNoneMean = Median = Mode
Negative skewLeftMean < Median < Mode
UNIT 06 Correlation & Regression
🔗 Pearson's Correlation Coefficient \(r\)
Definition form \[r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i-\bar{x})^2 \sum (y_i-\bar{y})^2}}\]
Computational form \[r = \frac{n\sum xy - \sum x \sum y}{\sqrt{\left[n\sum x^2 - (\sum x)^2\right]\left[n\sum y^2 - (\sum y)^2\right]}}\]
\[-1 \leq r \leq +1\]
Value of rMeaning
\(+1\)Perfect positive linear relationship
\(r > 0\)Positive — both rise together
\(0\)No linear relationship
\(r < 0\)Negative — one rises as other falls
\(-1\)Perfect negative linear relationship

⚠️ Correlation measures linear association only — and never implies causation.

📈 Least-Squares Regression Line
\[y = a + bx\]
Slope b \[b = \frac{n\sum xy - (\sum x)(\sum y)}{n\sum x^2 - (\sum x)^2}\]
Intercept a \[\bar{y} = a + b\bar{x} \;\Rightarrow\; a = \bar{y} - b\bar{x}\]
① Table: \(x, y, xy, x^2\) ② Find \(b\) ③ \(a = \bar{y} - b\bar{x}\) ④ Predict

💡 The line always passes through \((\bar{x}, \bar{y})\). "Least squares" minimises \(\sum(y_i - \hat{y}_i)^2\).

📋 Spearman's Rank Correlation \(\rho\)
\[\rho = 1 - \frac{6\sum d_i^2}{n(n^2 - 1)}\]
\(d_i\) = rank\((x)\) − rank\((y)\) \(n\) = number of observations \(-1 \leq \rho \leq +1\)
① Rank \(x\) and \(y\) ② \(d = R_x - R_y\) ③ \(\sum d^2\) ④ Apply formula
Value of rhoStrength
±1.00Perfect
±0.70 – ±0.99Strong
±0.40 – ±0.69Moderate
±0.10 – ±0.39Weak
0No correlation
Use for: ranked data, monotonic but non-linear relationships, or data with outliers
🔮 Interpolation

Estimating a value within two known values in a sequence.

✅ Reliable — stays inside the observed data range.

🚀 Extrapolation

Estimating a value by extending a known sequence beyond the area that is certainly known.

⚠️ Risky — the fitted relationship may not hold outside the data range.

KEY Relationships & When to Use
⚡ AM–GM–HM Inequality
\[HM \leq GM \leq AM\]
Equality holds only when all values are equal.
🔗 Empirical Relationship (Moderately Skewed)
Form 1 \[\text{Mean} - \text{Mode} = 3(\text{Mean} - \text{Median})\]
Form 2 \[\text{Mode} \approx 3\,\text{Median} - 2\,\text{Mean}\]
