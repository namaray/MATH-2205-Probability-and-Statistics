TOPIC Probability
📐 Range & Theoretical Probability
\[0 \leq P(E) \leq 1\]
\[P(E) = \frac{\text{favourable outcomes}}{\text{total outcomes}}\]

0 = impossible · 0.5 = even chance · 1 = certain

🔄 Complement Rule
\[P(A) + P(A') = 1\]
\[P(A) = 1 - P(A')\]

💡 Any "at least one" question → do "none" and subtract.

➕ Addition & Multiplication Rules
Addition rule — "A or B or both" \[P(A \cup B) = P(A) + P(B) - P(A \cap B)\]
Special cases
If the events areThen
Mutually exclusive (cannot co-occur)\(P(A \cap B) = 0\) so \(P(A \cup B) = P(A)+P(B)\)
Independent (no influence)\(P(A \cap B) = P(A) \times P(B)\)
Dependent (one affects the other)\(P(A \cap B) = P(A) \cdot P(B \mid A)\)

⚠️ Mutually exclusive ≠ independent. Exclusive events never co-occur; independent ones often do, just without influencing each other.

💡 "Exactly one of A, B" = \(P(A \cup B) - P(A \cap B)\).

🌿 Conditional Probability & Tree Diagrams
\[P(B \mid A) = \frac{P(A \cap B)}{P(A)}, \qquad P(A) > 0\]
① Multiply ALONG a branch ② Add ACROSS branches

Branches leaving any one node always sum to 1 — use it to check the tree.

Law of total probability \[P(B) = P(B \mid A)P(A) + P(B \mid A')P(A')\]

💡 This is just "add every path that ends in B" — it is how you get the denominator for Bayes.

🔁 Bayes' Theorem
\[P(A \mid B) = \frac{P(B \mid A) \times P(A)}{P(B)}\]
Posterior = (Likelihood × Prior) ÷ Evidence
TermNameMeaning
\(P(A \mid B)\)PosteriorProbability of A given B
\(P(B \mid A)\)LikelihoodProbability of B given A
\(P(A)\)PriorInitial probability of A
\(P(B)\)EvidenceTotal probability of B
Use when: the question reverses a condition — "given the outcome, what caused it?" (positive test → does the patient have the disease?)
UNIT 07 The Probability Distribution
🎲 Discrete Probability Distribution
\(X\)\(x_1\)\(x_2\)\(x_3\)…\(x_n\)
\(P(X=x)\)\(p_1\)\(p_2\)\(p_3\)…\(p_n\)
Two conditions that must hold
① \(p(x) \geq 0\) for every x ② \(\sum p(x) = 1\)
Mean = Expected Value \[\mu = E(x) = \sum x\,p(x)\]
Variance \[\text{Var}(x) = \sum x^2 p(x) - \big(E(x)\big)^2\]
Build the table, then the \(xp(x)\) and \(x^2p(x)\) columns. Variance = mean of squares − square of the mean.
🎯 Binomial / Bernoulli Distribution
\[X \sim \beta(n, p) \qquad P(X = r) = {}^{n}C_r \, p^r q^{\,n-r}\]
\(n\) = number of trials \(r = 0,1,2,\ldots,n\) \(p\) = P(success) \(q = 1-p\) = P(failure) \({}^{n}C_r = \frac{n!}{r!(n-r)!}\)
Mean \[\mu = E(x) = np\]
Variance \[\sigma^2 = npq\]
Three criteria (all must hold)
① Fixed number of trials ② Trials independent ③ p the same every trial

💡 Given mean & variance, recover the parameters: \(q = \frac{\sigma^2}{\mu}\), then \(p = 1-q\) and \(n = \frac{\mu}{p}\).

💡 "More than 1" / "fewer than k" → use the complement: \(P(X > 1) = 1 - P(0) - P(1)\).

⏱️ Poisson Distribution
\[X \sim P_0(\mu) \qquad P(X = r) = \frac{e^{-\mu} \times \mu^{\,r}}{r!}\]
\(\mu\) = mean events per interval \(r = 0,1,2,\ldots\) (no upper limit) \(e \approx 2.71828\)
Mean = Variance \[E(x) = \sigma^2 = \mu\]
Three conditions
① Events occur singly ② Constant average rate ③ Events independent

⏱️ Rescale first. Rate × interval = \(\mu\). Once every 48 h → in 60 h, \(\mu = \frac{60}{48} = 1.25\); in 24 h, \(\mu = 0.5\).

➕ Independent Poissons add: \(X \sim P_0(\mu_1)\), \(Y \sim P_0(\mu_2)\) ⇒ \(X+Y \sim P_0(\mu_1+\mu_2)\).

💡 \(P(X \geq 1) = 1 - P(X = 0) = 1 - e^{-\mu}\).

🔔 Normal (Gaussian) Distribution
\[X \sim N(\mu, \sigma)\]
Probability density function \[f(x) = \frac{1}{\sigma\sqrt{2\pi}}\; e^{-\frac{(x-\mu)^2}{2\sigma^2}}\]
\(f(x)\) = probability density \(x\) = value of the variable \(\mu\) = mean \(\sigma\) = standard deviation \(\sigma^2\) = variance
Properties
ContinuousNot a count — a measurement on a scale
SymmetricHalf the values below the mean, half above
CentreMean = Median = Mode
Described byJust two values: \(\mu\) and \(\sigma\)
SupportNon-zero over the entire real line
📏 Empirical Rule (68–95–99.7)
IntervalContains
\(\mu \pm 1\sigma\)≈ 68% of values (34% each side)
\(\mu \pm 2\sigma\)≈ 95% of values (+13.5% each side)
\(\mu \pm 3\sigma\)≈ 99.7% of values (+2.35% each side)
Beyond \(3\sigma\) only about 0.15% remains in each tail.
📐 Standardising — the z-Score
\[z = \frac{x - \mu}{\sigma} \qquad Z \sim N(0, 1)\]
\[P(X < x) = P\!\left(Z < \tfrac{x-\mu}{\sigma}\right) = \Phi(z)\]
You wantUse
\(P(Z > z)\)\(1 - \Phi(z)\)
\(P(Z < -z)\)\(1 - \Phi(z)\) (symmetry)
\(P(a < Z < b)\)\(\Phi(b) - \Phi(a)\)
\(\Phi(1) \approx 0.8413\) \(\Phi(2) \approx 0.9772\) \(\Phi(3) \approx 0.9987\)

📎 Not in the Unit 07 handout, but needed to turn a normal curve into an actual probability.

UNIT 09 Continuous Probability Distribution
📈 Probability Density Function (pdf)
Three properties
① \(f(x) \geq 0\) for all x ② \(\int_{-\infty}^{\infty} f(x)\,dx = 1\) ③ \(P(a < X \leq b) = \int_a^b f(x)\,dx\)
Mean \[E(x) = \mu = \int x\,f(x)\,dx\]
Variance \[\sigma^2 = \int x^2 f(x)\,dx - [E(x)]^2\]

⚠️ \(P(X = c) = 0\) always, so \(<\) and \(\leq\) give the same answer. \(f(x)\) is a density, not a probability — it can exceed 1.

💡 Unknown constant \(k\)? Set \(\int f(x)\,dx = 1\) and solve. "Show it's a pdf" needs both \(f \geq 0\) and area = 1.

💡 Symmetric pdf → the mean is the centre of symmetry, no integration needed.

Same as Unit 07 discrete, with \(\sum\) → \(\int\) and \(p(x)\) → \(f(x)\,dx\).
📐 cdf, Median, Quartiles & Mode
Cumulative distribution function \[F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\,dt \qquad f(x) = F'(x)\]
\[F(x) = \begin{cases} 0, & x < a \\ \int_a^x f(t)\,dt, & a \leq x \leq b \\ 1, & x > b \end{cases}\]
FindSolve
Median m\(F(m) = 0.5\)
Lower quartile\(F(Q_1) = 0.25\)
Upper quartile\(F(Q_3) = 0.75\)
Mode\(f'(x) = 0\), check \(f''(x) < 0\) and the endpoints
Probability\(P(c < X \leq d) = F(d) - F(c)\)

✅ Check \(F(a) = 0\) and \(F(b) = 1\). Median/quartile equations are usually quadratics — keep the root inside the range.

WORKSHEET 02 Estimation & Hypothesis Testing
🎯 Confidence Intervals
Shape of every interval \[\text{estimate} \pm z \times SE\]
SituationInterval
Mean, σ known\(\bar{x} \pm z\,\sigma/\sqrt{n}\)
Mean, σ unknown, large n\(\bar{x} \pm z\,s/\sqrt{n}\)
Proportion\(\hat{p} \pm z\sqrt{\hat{p}(1-\hat{p})/n}\)
Unbiased estimates from Σx, Σx² \[\bar{x} = \frac{\sum x}{n} \qquad s^2 = \frac{1}{n-1}\left(\sum x^2 - \frac{(\sum x)^2}{n}\right)\]
90% → z = 1.645 95% → z = 1.960 98% → z = 2.326 99% → z = 2.576

💡 Given a width: \(z = \dfrac{\text{width}}{2 \times SE}\), then confidence \(= 2\Phi(z) - 1\).

💡 Claimed value inside the interval → consistent with the data. Outside → evidence against it.

⚖️ Hypothesis Testing (Binomial & Poisson)
① Define X and its distribution ② \(H_0\): old value · \(H_1\): the claim ③ P(result this extreme | \(H_0\)) ④ Compare with level ⑤ Conclude in context
Claim saysH₁Find
"lower" / "reduced"\(p < p_0\)\(P(X \leq \text{obs})\)
"higher" / "increased"\(p > p_0\)\(P(X \geq \text{obs})\)
"different" / "changed"\(p \neq p_0\)Two-tailed: compare with half the level
Decision
Probability < levelReject \(H_0\) — significant evidence for \(H_1\)
Probability ≥ levelDo not reject \(H_0\) — insufficient evidence

⏱️ Poisson over a longer period: scale λ first (7/month → 42 over 6 months). Large λ → approximate by \(N(\lambda, \lambda)\) with continuity correction: \(X \leq 32\) → \(X < 32.5\).

⚠️ Never write "accept \(H_0\)" — write "insufficient evidence to reject \(H_0\)".
