Question 1 — Simple Probability

📝 Question
Show solution

Probability = (number of outcomes you want) ÷ (total number of outcomes). Picture all 36 students lined up: “one particular boy” is just 1 of them, and “a girl” is any of 24.

Total students
\[12 + 24 = 36\]
(a) A particular boy

"A particular boy" means one specific, named boy — a single outcome out of 36:

\[P = \frac{1}{36}\]
(b) A girl
\[P = \frac{24}{36} = \frac{2}{3}\] (a) 1/36 ≈ 0.0278  ·  (b) 2/3 ≈ 0.667

Question 4 — Expected Number

📝 Question
Show solution

Expected number = probability × number of tries. Two of the eight equal sectors show a 4, so a 4 comes up a quarter of the time. For (b), find the total spins needed, then subtract the 400 already done.

The probability of a 4

Of the eight equal sectors (4, 1, 3, 3, 2, 4, 3, 5), exactly two carry a 4:

\[P(4) = \frac{2}{8} = \frac14 \qquad P(\text{not }4) = 1 - \frac14 = \frac34\]
(a) Expected number of non-4s in 400 spins
\[400 \times \frac34 = 300\]
(b) Spins needed for an expected 160 fours

In \(n\) spins the expected number of 4s is \(\frac{n}{4}\). Setting that to at least 160:

\[\frac{n}{4} \geq 160 \quad\Longrightarrow\quad n \geq 640\]

The question asks how many more spins are needed, and Axel has already done 400:

\[640 - 400 = 240\] (a) 300 times  ·  (b) 240 more spins

Question 5 — Venn Diagram with Unknowns

📝 Question
Show solution

Work from the outside in. 10 boys are outside both circles, so 15 are inside at least one. Chess holds 9 of those 15, so the other 6 must be debating-only. Then the overlap and chess-only follow.

(a) Setting up the equations

Total in at least one club:

\[a + b + c = 25 - 10 = 15\]

Chess members and debating members:

\[a + b = 9 \qquad b + c = 8\]
Solving

Subtract \(a + b = 9\) from \(a + b + c = 15\):

\[c = 15 - 9 = 6\]

Then from \(b + c = 8\):

\[b = 8 - 6 = 2\]

And from \(a + b = 9\):

\[a = 9 - 2 = 7\]

Check: \(7 + 2 + 6 + 10 = 25\) ✓

(b)(i) Chess or debating
\[P(C \cup D) = \frac{a+b+c}{25} = \frac{15}{25} = \frac35 = 0.6\]
(b)(ii) Exactly one club

"Exactly one" excludes the overlap \(b\):

\[P = \frac{a + c}{25} = \frac{7 + 6}{25} = \frac{13}{25} = 0.52\] (a) a = 7, b = 2, c = 6  ·  (b)(i) 0.6  ·  (b)(ii) 0.52

Question 6 — Addition Rule

📝 Question
Show solution

Put the overlap (0.2) in the middle first, then subtract it from each event to get the “only” parts. Every answer can then be read straight off the diagram.

(a) Mutually exclusive?

No. Mutually exclusive events cannot happen together, which requires \(P(X \cap Y) = 0\). Here \(P(X \cap Y) = 0.2 \neq 0\), so the events can occur together and are not mutually exclusive.

(b) P(X ∪ Y)
\[P(X \cup Y) = P(X) + P(Y) - P(X \cap Y) = 0.5 + 0.6 - 0.2 = 0.9\]
(c) X or Y but not both

Take the union and remove the overlap:

\[P(\text{exactly one}) = P(X \cup Y) - P(X \cap Y) = 0.9 - 0.2 = 0.7\]

Equivalently, add the two "only" regions: \((0.5 - 0.2) + (0.6 - 0.2) = 0.3 + 0.4 = 0.7\) ✓

(a) Not mutually exclusive, since P(X ∩ Y) = 0.2 ≠ 0  ·  (b) 0.9  ·  (c) 0.7

Question 7 — Independent Events

📝 Question
Show solution

Each set of lights is a separate “stop (0.2) or go (0.8)” moment. Multiply along a path to get that path’s probability, and add up all the paths that match what you want. “Stops at any” means “at least one stop” — easiest as 1 minus “never stops”.

Setting up

\(P(\text{stop}) = 0.2\) and \(P(\text{go}) = 0.8\) at each set, and the three sets are independent — so probabilities along a path multiply.

(a) First stop is at the second set

This means she goes through the first set and then stops at the second. What happens at the third set is irrelevant:

\[P = 0.8 \times 0.2 = 0.16\]
(b) Stops at exactly one set

One stop and two goes, and the stop could be at any of the three sets:

\[P = {}^{3}C_1 \times (0.2)(0.8)^2 = 3 \times 0.2 \times 0.64 = 0.384\]
(c) Stops at any set of lights

"Any" here means at least one — so use the complement of stopping at none:

\[P(\text{at least one stop}) = 1 - (0.8)^3 = 1 - 0.512 = 0.488\] (a) 0.16  ·  (b) 0.384  ·  (c) 0.488

Question 8 — Biased Coin

📝 Question
Show solution

“Three heads in a row” is p × p × p = p³, so take the cube root to find p. “No heads” is three tails in a row: (1 − p)³.

Find p from the given information

Let \(p = P(\text{head})\). The three tosses are independent, so:

\[p^3 = \frac{125}{512}\]

Both 125 and 512 are perfect cubes (\(5^3\) and \(8^3\)):

\[p = \sqrt[3]{\frac{125}{512}} = \frac{5}{8}\]
No heads in three tosses

"No heads" means three tails, and \(P(\text{tail}) = 1 - \frac58 = \frac38\):

\[P(\text{no heads}) = \left(\frac38\right)^3 = \frac{27}{512}\] 27/512 ≈ 0.0527

Question 9 — Tree Diagram & Bayes

📝 Question
Show solution

Read the tree left to right, multiplying along each path. For (b), look only at the paths where Mina didn’t enjoy the meal, and ask what fraction of that total came from Sunil cooking.

(a) Finding x

If \(P(\text{not enjoy} \mid \text{take-away}) = x\), then \(P(\text{enjoy} \mid \text{take-away}) = 1 - x\). Multiplying along that branch:

\[P(\text{buys} \cap \text{enjoys}) = 0.24(1 - x) = 0.156\] \[1 - x = \frac{0.156}{0.24} = 0.65 \quad\Longrightarrow\quad x = 0.35\]
(b) Building the tree

\(P(\text{cooks}) = 1 - 0.24 = 0.76\), and \(P(\text{not enjoy} \mid \text{cooks}) = 1 - 0.75 = 0.25\).

PathCalculationProbability
Cooks ∩ not enjoy\(0.76 \times 0.25\)0.190
Buys ∩ not enjoy\(0.24 \times 0.35\)0.084
P(not enjoy)\(0.190 + 0.084\)0.274
Apply the conditional probability formula
\[P(\text{cooked} \mid \text{not enjoy}) = \frac{P(\text{cooked} \cap \text{not enjoy})}{P(\text{not enjoy})} = \frac{0.190}{0.274}\] \[= \frac{190}{274} = \frac{95}{137} = 0.6934\]

This is Bayes' theorem in action: the condition has been reversed from "given he cooked, did she enjoy it?" to "given she didn't enjoy it, did he cook?"

(a) x = 0.35  ·  (b) 95/137 ≈ 0.693

Question 10 — Discrete Random Variable

📝 Question
Show solution

Write each probability as k × x², add them all up, and set the total to 1 — that pins down k. E(X) is then the “balance point” of the distribution, and Var(X) measures how spread out it is.

(i) The table in terms of k
\(x\)\(-1\)123
\(P(X=x)\)\(k\)\(k\)\(4k\)\(9k\)

Note \((-1)^2 = 1\), so the first entry is \(k\), not \(-k\) — probabilities can never be negative.

Finding k

The probabilities must sum to 1:

\[k + k + 4k + 9k = 15k = 1 \quad\Longrightarrow\quad k = \frac{1}{15}\]

So the distribution is \(\frac{1}{15}, \frac{1}{15}, \frac{4}{15}, \frac{9}{15}\).

(ii) E(X)
\[E(X) = (-1)\tfrac{1}{15} + (1)\tfrac{1}{15} + (2)\tfrac{4}{15} + (3)\tfrac{9}{15} = \frac{-1 + 1 + 8 + 27}{15} = \frac{35}{15} = \frac73\]
Var(X)
\[E(X^2) = (1)\tfrac{1}{15} + (1)\tfrac{1}{15} + (4)\tfrac{4}{15} + (9)\tfrac{9}{15} = \frac{1 + 1 + 16 + 81}{15} = \frac{99}{15} = \frac{33}{5}\] \[\text{Var}(X) = \frac{33}{5} - \left(\frac73\right)^2 = \frac{33}{5} - \frac{49}{9} = \frac{297 - 245}{45} = \frac{52}{45}\] k = 1/15  ·  E(X) = 7/3 ≈ 2.33  ·  Var(X) = 52/45 ≈ 1.156
