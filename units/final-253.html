Question 1 — Estimation & Hypothesis Testing

Q1(a) — Confidence Interval for a Mean [3]

📝 Question
Show solution

Build the interval exactly like class: find \(z\) for 90%, work out the margin of error \(c\), then step \(c\) down and up from \(\bar{x}\).

Given
\[n = 64, \qquad \bar{x} = 5.2, \qquad \sigma \approx s = 1.6\]

The 1.6 is the sample standard deviation, but \(n = 64\) is large, so we can use it in place of \(\sigma\) and still use \(z\).

Find z for 90%

90% in the middle leaves 5% in each tail, so look up 95%:

\[z_{95\%} = 1.645\]
Margin of error c
\[c = z \times \frac{\sigma}{\sqrt{n}} = 1.645 \times \frac{1.6}{\sqrt{64}} = 1.645 \times 0.2 = 0.329\]
The interval
\[\bar{x} - c \;<\; \mu \;<\; \bar{x} + c\] \[5.2 - 0.329 \;<\; \mu \;<\; 5.2 + 0.329\] \[4.871 \;<\; \mu \;<\; 5.529\] 90% CI: 4.871 < μ < 5.529 hours (≈ 4.87 to 5.53)

Q1(b) — One-tailed Test for a Mean [5]

📝 Question
Show solution

Assume the batteries last exactly 80 hours on average. How unusual would a sample mean of 82 be? If it's rarer than 5%, that supports the claim that they last longer.

Step 1 — Setting the null and alternative hypotheses

The claim is “more than 80 hours”, so it goes in \(H_1\):

\[H_0: \mu = 80 \qquad H_1: \mu > 80\]
Step 2 — Setting the level of significance (α)

\(\alpha = 0.05\), one-tailed (right), because the claim is “more than”.

Step 3 — Calculating the test statistic
\[z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{82 - 80}{4/\sqrt{16}} = \frac{2}{1} = 2.0\]
Step 4 — Calculating the p-value
\[\text{p-value} = P(Z > 2.0) = 1 - \Phi(2.0) = 1 - 0.9772 = 0.0228\]

Using the rejection region instead: right-tailed at 5%, reject if \(z > 1.645\). Here \(z = 2.0\), which is in the rejection region.

Step 5 — Making a decision about the null hypothesis

\(0.0228 < 0.05\), so there exists sufficient evidence to reject \(H_0\).

Step 6 — Stating an overall conclusion

At the 5% level, there is sufficient evidence to support the manufacturer's claim that the mean battery lifespan is more than 80 hours.

📎 z or t?

Strictly, with \(\sigma\) unknown and only 16 batteries, a textbook would use a t-test: \(t = 2.0\) with 15 degrees of freedom, critical value 1.753, p ≈ 0.032. That gives the same decision. Your course and this paper only use \(z\), so the z-test above is what's expected.

z = 2.0 > 1.645, p = 0.0228 < 0.05 → reject H₀ · the claim (μ > 80 hours) is supported

Q1(c) — Sketch the Critical Region [2]

📝 Question
Show solution

“Two-tailed” means extreme results in either direction count against \(H_0\). So the 5% is split into two halves, 2.5% in each tail.

Find the critical z values

Each tail holds 2.5%, so the area to the left of the upper cut-off is 97.5%:

\[z_{97.5\%} = 1.96 \qquad\text{so the critical values are } \pm 1.96\]
The sketch

To draw it in the exam: a bell curve centred at 0, cut-off lines at \(-1.96\) and \(+1.96\), and both tails shaded and labelled “rejection region, 2.5%”. Label the middle “acceptance region, 95%”.

What it means

Reject \(H_0\) if \(z < -1.96\) or \(z > 1.96\). Otherwise there is insufficient evidence to reject \(H_0\).

Critical region: z < −1.96 or z > 1.96 (2.5% in each tail); acceptance region −1.96 ≤ z ≤ 1.96

Question 2 — Probability & Discrete Distributions

Q2(a) — Independent Events [2]

📝 Question
Show solution

“Independent” lets you multiply to get “both”. Then the addition rule gives “either” — remembering to subtract the overlap so it isn't counted twice.

Both events (independent → multiply)
\[P(A \cap B) = P(A) \times P(B) = 0.6 \times 0.4 = 0.24\]
Either event (addition rule)
\[P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.6 + 0.4 - 0.24 = 0.76\] P(A ∪ B) = 0.76

Q2(b) — Bayes' Theorem [3]

📝 Question
Show solution

Of everyone who tests positive, how many are actually sick? Surprisingly few: 5% of the huge healthy group outnumbers 90% of the tiny sick group. So most positives are false alarms.

Set up

Let \(D\) = has the disease and \(+\) = tests positive.

\[P(D) = 0.02 \qquad P(+ \mid D) = 0.90 \qquad P(+ \mid D') = 0.05 \qquad P(D') = 0.98\]
Total probability of a positive test
\[P(+) = P(D)P(+ \mid D) + P(D')P(+ \mid D') = 0.02(0.90) + 0.98(0.05) = 0.018 + 0.049 = 0.067\]
Bayes' theorem
\[P(D \mid +) = \frac{P(+ \mid D) \times P(D)}{P(+)} = \frac{0.018}{0.067} = 0.2687\] P(disease | positive) = 18/67 ≈ 0.269 — only about 27%

Q2(c) — Discrete Probability Distribution [5]

📝 Question
Show solution

A valid distribution needs every probability ≥ 0 and a total of exactly 1. The mean is \(\sum x\,p(x)\), and the variance is the mean of the squares minus the square of the mean.

Build the table
\(x\)\(p(x)\)\(x\,p(x)\)\(x^2 p(x)\)
00.4000
10.300.300.30
20.200.400.80
30.100.300.90
Total1.001.002.00
(i) Valid?

Every \(p(x) \geq 0\), and \(\sum p(x) = 0.40 + 0.30 + 0.20 + 0.10 = 1\). Both conditions hold, so it is a valid probability distribution.

(ii) Mean
\[E(X) = \sum x\,p(x) = 0 + 0.30 + 0.40 + 0.30 = 1 \text{ day}\]
(iii) Variance
\[E(X^2) = \sum x^2 p(x) = 0 + 0.30 + 0.80 + 0.90 = 2\] \[\text{Var}(X) = E(X^2) - [E(X)]^2 = 2 - 1^2 = 1\] (i) valid: all p(x) ≥ 0 and Σp(x) = 1 · (ii) E(X) = 1 day · (iii) Var(X) = 1 day²

Question 3 — Normal, Binomial & Poisson

Q3(a) — Normal Distribution [4]

📝 Question
Show solution

Convert both ends to z-scores, then the answer is the area between them. 25 and 35 are each exactly one standard deviation from the mean, so expect about 68%.

Standardise both limits

\(X \sim N(30, 5^2)\), so \(\sigma = 5\):

\[z_1 = \frac{25 - 30}{5} = -1 \qquad z_2 = \frac{35 - 30}{5} = 1\]
Area between them
\[P(25 < X < 35) = P(-1 < Z < 1) = \Phi(1) - \Phi(-1) = 0.8413 - 0.1587 = 0.6826\] ≈ 0.6826, i.e. about 68.26% of households

Q3(b) — Binomial: “At Least One” [3]

📝 Question
Show solution

“At least one” covers 1, 2, 3, … all the way to 20 — far too many cases. The opposite is just “none”, so work that out and subtract it from 1.

Identify the distribution

Fixed number of trials (20 customers), each a drop or not, \(p = 0.02\):

\[X \sim B(20, 0.02)\]
Use the complement
\[P(X \geq 1) = 1 - P(X = 0) = 1 - \binom{20}{0}(0.02)^0(0.98)^{20} = 1 - 0.98^{20}\] \[= 1 - 0.6676 = 0.3324\] P(at least one call drop) ≈ 0.3324

Q3(c) — Poisson with a Rescaled Rate [3]

📝 Question
Show solution

The rate is given per hour, but the question asks about 30 minutes, so halve it first. “No more than 1” means 0 or 1 complaints.

Rescale the rate
\[\lambda = 3 \times \tfrac{30}{60} = 1.5 \qquad X \sim Po(1.5)\]
No more than 1
\[P(X \leq 1) = P(0) + P(1) = \frac{1.5^0 e^{-1.5}}{0!} + \frac{1.5^1 e^{-1.5}}{1!} = e^{-1.5}(1 + 1.5)\] \[= 0.2231 \times 2.5 = 0.5578\] P(X ≤ 1) ≈ 0.5578

Question 4 — Continuous Random Variable [10]

📝 Question
Show solution

Same routine as Unit 09: total area = 1 gives \(k\); integrating from 0 up to \(t\) gives the cdf; the cdf gives probabilities; and the mode is where the curve peaks, where \(f'(t) = 0\).

(i) Find k [2]

For \(0 \leq t \leq 10\), \(t(10 - t) \geq 0\), so \(f(t) \geq 0\) as long as \(k > 0\). Now set the total area to 1:

\[\int_0^{10} k\,t(10 - t)\,dt = k\int_0^{10}(10t - t^2)\,dt = k\left[5t^2 - \frac{t^3}{3}\right]_0^{10} = k\left(500 - \frac{1000}{3}\right) = \frac{500k}{3}\] \[\frac{500k}{3} = 1 \quad\Longrightarrow\quad k = \frac{3}{500} = 0.006\]
(ii) The cdf [3]
\[F(t) = \int_0^{t}\frac{3}{500}(10u - u^2)\,du = \frac{3}{500}\left(5t^2 - \frac{t^3}{3}\right) = \frac{15t^2 - t^3}{500}\] \[F(t) = \begin{cases} 0, & t < 0 \\[4pt] \dfrac{15t^2 - t^3}{500}, & 0 \leq t \leq 10 \\[4pt] 1, & t > 10 \end{cases}\]

Check: \(F(0) = 0\) and \(F(10) = \frac{1500 - 1000}{500} = 1\). ✓

(iii) Served in under 4 minutes [3]
\[P(T < 4) = F(4) = \frac{15(16) - 64}{500} = \frac{240 - 64}{500} = \frac{176}{500} = 0.352\]
(iv) The mode [2]
\[f'(t) = k(10 - 2t) = 0 \quad\Longrightarrow\quad t = 5\]

\(f''(t) = -2k < 0\), so this is a maximum. The mode is 5 minutes. (The curve is a parabola symmetric about \(t = 5\), so the mean and median are also 5.)

(i) k = 3/500 = 0.006 · (ii) F(t) = (15t² − t³)/500 on [0, 10] · (iii) 0.352 · (iv) mode = 5 minutes
