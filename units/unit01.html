UNIT 01 · MID TERM

Introduction to Statistics

SECTION 1: What is Statistics?

Definition: Statistics is a branch of mathematics that involves the collection, analysis, interpretation, presentation, and organization of data. It provides methods for making inferences and decisions in the presence of uncertainty.

Why Do We Need Statistics?

  • Understanding statistics helps make better choices
  • Statistics translates data into knowledge
  • Helps understand the world around us
Historical Note: Dr. John Snow's data-driven discovery of cholera transmission in 1854 London is one of the earliest examples of applied statistics.

SECTION 2: Branches of Statistics

Statistics is broadly divided into two major branches.

📋

Descriptive Statistics

The branch that focuses on collecting, summarizing, and presenting a set of data.

🔍

Inferential Statistics

The branch that analyzes sample data to draw conclusions about a population.

SECTION 3: Key Terminology

Term Definition
Population The set of all subjects in which we are interested
Sample A representative part of population selected for analysis
Variable A symbol or name used to represent a value that can change or vary
Statistic A numerical measure that describes a characteristic of a sample
Parameter A numerical measure that describes a characteristic of a population

Population vs Sample

🌍

Population

The 'large group' — all items, individuals, or subjects about which you want to draw a conclusion.

🧪

Sample

The 'small group' — a portion of the population selected for analysis, often randomly selected.

SECTION 4: Types of Variables

Categorical (Qualitative) Variables

Describes data divided into distinct categories or groups. Cannot be measured numerically; described with labels or names.

Examples: Marital Status, Political Party, Eye Color

Numerical (Quantitative) Variables

Represents data in numerical form, allows mathematical operations like addition, subtraction, and averaging.

Discrete Variables

Take finite or countable number of values. Usually represent items counted in whole numbers.

📝 Examples: Number of students in a class (25, 30, 45); Number of cars in a parking lot (5, 10, 15)

Continuous Variables

Can take infinite number of values within a given range, including fractions and decimals.

📝 Examples: Height of individuals (5.8 feet, 6.2 feet); Weight of an object (50.5 kg, 73.2 kg)
