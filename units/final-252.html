Question 1 — Binomial, Poisson & Normal [10]

Q1(a) — Binomial: Exactly 3 [2]

📝 Question
Show solution

A fixed number of modules (12), each buggy or not, with the same chance 0.1 — that's binomial. “Exactly 3” is one term of the formula.

Identify the distribution
\[X \sim B(12, 0.1)\]
Exactly 3
\[P(X = 3) = \binom{12}{3}(0.1)^3(0.9)^9 = 220 \times 0.001 \times 0.3874 = 0.0852\] P(X = 3) ≈ 0.0852

Q1(b) — Poisson: At Least One [3]

📝 Question
Show solution

The rate is per second, but the question asks about two seconds, so double it first. “At least 1” is easiest as 1 minus “none”.

Rescale the rate
\[\lambda = 4 \times 2 = 8 \qquad X \sim Po(8)\]
At least one
\[P(X \geq 1) = 1 - P(X = 0) = 1 - \frac{8^0 e^{-8}}{0!} = 1 - e^{-8} = 1 - 0.000335 = 0.9997\] P(X ≥ 1) ≈ 0.9997

Q1(c) — Normal: Less Than 2 Seconds [3]

📝 Question
Show solution

Turn 2 seconds into a z-score, then read the area to its left. 2 is below the mean of 2.5, so expect a small probability.

Standardise

\(X \sim N(2.5, 0.4^2)\):

\[z = \frac{2 - 2.5}{0.4} = -1.25\]
Area to the left
\[P(X < 2) = P(Z < -1.25) = 1 - \Phi(1.25) = 1 - 0.8944 = 0.1056\] P(X < 2) ≈ 0.1056

Q1(d) — Within One Standard Deviation [2]

📝 Question
Show solution

Standardising turns \(\mu - \sigma\) into \(z = -1\) and \(\mu + \sigma\) into \(z = 1\), whatever \(\mu\) and \(\sigma\) are. So the answer is the same for every normal distribution.

Standardise both ends
\[\frac{(\mu - \sigma) - \mu}{\sigma} = -1 \qquad \frac{(\mu + \sigma) - \mu}{\sigma} = 1\]
Area between
\[P(\mu - \sigma < X < \mu + \sigma) = P(-1 < Z < 1) = \Phi(1) - \Phi(-1) = 0.8413 - 0.1587 = 0.6826\]

This is the “68%” of the empirical rule. (The paper writes \(X \sim N(\sim\mu, \sigma^2)\) — the extra “~” is a typo for \(X \sim N(\mu, \sigma^2)\).)

≈ 0.6826 (about 68%)

Question 2 — Continuous Random Variable [10]

Q2(a)–(e) — Backup Time

📝 Question
Show solution

The Unit 09 routine: area = 1 gives \(k\); integrating from 0 up to \(x\) gives the cdf; the cdf gives probabilities and the median; and \(\int x\,f(x)\,dx\) gives the mean.

(a) Find k [2]

For \(0 \leq x \leq 10\), \(10 - x \geq 0\), so \(f(x) \geq 0\) as long as \(k > 0\). Now set the total area to 1:

\[\int_0^{10} k(10 - x)\,dx = k\left[10x - \frac{x^2}{2}\right]_0^{10} = k(100 - 50) = 50k = 1 \quad\Longrightarrow\quad k = \frac{1}{50} = 0.02\]
(b) The cdf [2]
\[F(x) = \int_0^{x}\frac{10 - u}{50}\,du = \frac{1}{50}\left(10x - \frac{x^2}{2}\right) = \frac{20x - x^2}{100}\] \[F(x) = \begin{cases} 0, & x < 0 \\[4pt] \dfrac{20x - x^2}{100}, & 0 \leq x \leq 10 \\[4pt] 1, & x > 10 \end{cases}\]

Check: \(F(0) = 0\) and \(F(10) = \frac{200 - 100}{100} = 1\). ✓

(c) Less than 5 minutes [2]
\[P(X < 5) = F(5) = \frac{100 - 25}{100} = 0.75\]
(d) Expected time [2]
\[E(X) = \int_0^{10} x \cdot \frac{10 - x}{50}\,dx = \frac{1}{50}\left[5x^2 - \frac{x^3}{3}\right]_0^{10} = \frac{1}{50}\left(500 - \frac{1000}{3}\right) = \frac{10}{3} \approx 3.33 \text{ min}\]
(e) Median [2]

Here F(m) = 0.5 is the right method — that's the definition of the median:

\[\frac{20m - m^2}{100} = 0.5 \;\Longrightarrow\; m^2 - 20m + 50 = 0 \;\Longrightarrow\; m = \frac{20 \pm \sqrt{400 - 200}}{2} = 10 \pm \sqrt{50}\]

\(10 + \sqrt{50} \approx 17.07\) is outside \(0 \leq x \leq 10\), so \(m = 10 - \sqrt{50} \approx 2.93\) minutes.

Median ≠ Mode

F(m) = 0.5 finds the median. The mode is where f is highest: this f slopes downward, so its mode is at \(x = 0\) — a different answer. Use \(f'(x) = 0\) (or check the endpoints) for the mode, and \(F(m) = 0.5\) for the median.

(a) k = 1/50 · (b) F(x) = (20x − x²)/100 on [0, 10] · (c) 0.75 · (d) E(X) = 10/3 ≈ 3.33 min · (e) median = 10 − √50 ≈ 2.93 min

Question 3 — Estimation & Hypothesis Testing [10]

Q3(a) — Confidence Interval for a Proportion [2]

📝 Question
Show solution

Start from the sample proportion \(\hat{p} = x/n\), work out the margin of error \(c\), then step \(c\) down and up from \(\hat{p}\).

Sample proportion
\[\hat{p} = \frac{x}{n} = \frac{126}{200} = 0.63\]
Find z for 95%

2.5% in each tail, so look up 97.5%: \(z_{97.5\%} = 1.96\).

Margin of error c
\[c = z \times \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}} = 1.96 \times \sqrt{\frac{0.63 \times 0.37}{200}} = 1.96 \times 0.03414 = 0.0669\]
The interval
\[\hat{p} - c \;<\; p \;<\; \hat{p} + c\] \[0.63 - 0.0669 \;<\; p \;<\; 0.63 + 0.0669\] \[0.563 \;<\; p \;<\; 0.697\] 95% CI: 0.563 < p < 0.697

Q3(b)(i) — One-tailed Test for a Mean [5]

📝 Question
Show solution

Assume the training did nothing (mean still 60 wpm). How unusual is a sample mean of 62.3 from 40 clerks? If it's rarer than 5%, the speed really has increased.

Step 1 — Setting the null and alternative hypotheses

The supervisor wants to show the mean is greater than 60, so that goes in \(H_1\):

\[H_0: \mu = 60 \qquad H_1: \mu > 60\]
Step 2 — Setting the level of significance (α)

\(\alpha = 0.05\), one-tailed (right).

Step 3 — Calculating the test statistic

\(n = 40\) is large, so the sample standard deviation 4.8 can stand in for \(\sigma\):

\[z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{62.3 - 60}{4.8/\sqrt{40}} = \frac{2.3}{0.7589} = 3.03\]
Step 4 — Calculating the p-value
\[\text{p-value} = P(Z > 3.03) = 1 - \Phi(3.03) = 1 - 0.9988 = 0.0012\]

Using the rejection region instead: right-tailed at 5%, reject if \(z > 1.645\). Here \(z = 3.03\), well inside it.

Step 5 — Making a decision about the null hypothesis

\(0.0012 < 0.05\), so there exists sufficient evidence to reject \(H_0\).

Step 6 — Stating an overall conclusion

At the 5% level, there is sufficient evidence that the training has increased the average typing speed above 60 wpm.

z = 3.03 > 1.645, p = 0.0012 < 0.05 → reject H₀ · the average speed has increased

Q3(b)(ii) — Type I and Type II Errors [2]

📝 Question
Show solution

A test can go wrong in two ways: raising a false alarm, or missing something that's really there.

Type I error (false positive)

Rejecting \(H_0\) when \(H_0\) is actually true. Its probability is the significance level \(\alpha\).

Type II error (false negative)

Failing to reject \(H_0\) when \(H_0\) is actually false. Its probability is written \(\beta\).

Question 4 — Probability & Discrete Distributions [10]

Q4(a) — Total Probability & Bayes [3]

📝 Question
Show solution

Draw the tree: pick a machine, then defective or not. (i) adds up every defective path. (ii) asks what fraction of those defective bolts came from Machine B.

Set up
\[P(A) = 0.6,\; P(D \mid A) = 0.03 \qquad P(B) = 0.4,\; P(D \mid B) = 0.05\]
(i) Probability a bolt is defective [1]
\[P(D) = P(A)P(D \mid A) + P(B)P(D \mid B) = 0.6(0.03) + 0.4(0.05) = 0.018 + 0.020 = 0.038\]
(ii) Defective, so from Machine B? [2]
\[P(B \mid D) = \frac{P(D \mid B)\,P(B)}{P(D)} = \frac{0.020}{0.038} = \frac{10}{19} = 0.5263\]

Machine B makes only 40% of the bolts but over half the defective ones, because its defect rate is higher.

(i) P(defective) = 0.038 · (ii) P(B | defective) = 10/19 ≈ 0.526

Q4(c) — Testing Independence [3]

📝 Question
Show solution

Read the probabilities straight from the totals. A and B are independent only if \(P(A \cap B)\) equals \(P(A) \times P(B)\) exactly.

(i) P(A) and P(B)
\[P(A) = \frac{100}{200} = 0.5 \qquad P(B) = \frac{140}{200} = 0.7\]
(ii) Test for independence
\[P(A \cap B) = \frac{80}{200} = 0.4 \qquad P(A) \times P(B) = 0.5 \times 0.7 = 0.35\]

\(0.4 \neq 0.35\), so A and B are not independent.

In words: owning a laptop changes the chance of subscribing. \(P(B \mid A) = \frac{80}{100} = 0.8\), compared with \(P(B) = 0.7\) overall.

(i) P(A) = 0.5, P(B) = 0.7 · (ii) P(A ∩ B) = 0.4 ≠ 0.35 = P(A)P(B) → not independent
