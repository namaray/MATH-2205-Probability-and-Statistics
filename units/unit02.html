UNIT 02 · MID TERM

Summarizing Data

1. Frequency Distribution

A frequency distribution is an overview of all distinct values in some variable and the number of times they occur. It tells how frequencies are distributed over values.

Example: Survey of households about pets.
Data: 3, 0, 1, 4, 4, 1, 2, 0, 2, 2, 0, 2, 0, 1, 3, 1, 2, 1, 1, 3

Steps for Creating a Frequency Table

1
Write the categories: List all unique values (0, 1, 2, 3, 4)
2
Tally the data: Go through each value and mark tallies
3
Count frequencies: Sum up tallies for each category

2. Bar Diagram

A bar diagram displays a vertical bar for each category. The height of the bar is the percentage or frequency of observations. Typically, the bars are apart, not side by side.

📊

Key Features

Used for categorical data. Bars don't touch each other. Height represents frequency or percentage.

Example: Bar Diagram of Shark Attacks by U.S. States shows individual categories clearly separated.

3. Pie Chart

A pie chart is a circle having a slice for each category. The size of a slice corresponds to the percentage of observations in the category.

\[ \text{Angle} = \frac{\text{Category Frequency}}{\text{Total Frequency}} \times 360^\circ \]
Each slice visually represents the proportion of data in that category, making it ideal for showing parts of a whole.

4. Histogram

A histogram is a graph that shows the frequency of numerical data using rectangles. The height represents the distribution frequency.

Steps for Constructing a Histogram

1
Divide the range: Split data into intervals of equal width. For discrete variables with few values, use actual values.
2
Count frequencies: Count the number of observations in each interval, forming a frequency table.
3
Draw the bars: On the horizontal axis, label endpoints. Draw a bar over each interval with height equal to its frequency.
Key Difference: In a histogram, bars touch each other because the data is continuous. In a bar diagram, bars are separated because the data is categorical.

5. Frequency Polygon

A frequency polygon is a line graph of class frequency plotted against class midpoint. Obtained by connecting the mid-points of the tops of histogram rectangles.

\[ \text{Class Midpoint} = \frac{\text{Lower Limit} + \text{Upper Limit}}{2} \]

6. Cumulative Frequency Polygon (Ogive)

A cumulative frequency polygon (ogive) shows cumulative frequencies. Cumulative percents are added from left to right. It plots cumulative frequency on the y-axis and class boundaries on the x-axis.

  • Also known as ogive
  • Shows running total of frequencies
  • Useful for finding median, quartiles, and percentiles
