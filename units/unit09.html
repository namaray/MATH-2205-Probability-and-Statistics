UNIT 09 · FINAL TERM

Continuous Probability Distribution

1. Discrete vs. Continuous Random Variables

Unit 07 dealt with discrete random variables, which take separate, countable values. A continuous random variable can take any value in an interval. The slides contrast two variables from the same emergency department:

DiscreteContinuous
ExampleThe number of patients visiting the emergency department per hourThe waiting time (in hours) a patient has to wait before seeing a doctor
Values0, 1, 2, 3, … (counted)Any value such as 1.37 h (measured)
Described byA probability table \(P(X = x)\)A probability density function \(f(x)\)
GraphSeparate spikesA smooth curve
Total probability\(\sum p(x) = 1\)\(\int f(x)\,dx = 1\)
💡 The One Big Idea

Every formula in this unit is the Unit 07 formula with \(\sum\) replaced by \(\int\) and \(p(x)\) replaced by \(f(x)\,dx\). If you know discrete expectation, you already know the structure.

2. Probability Density Function (pdf)

Definition: A random variable \(X\) is continuous if its probability density function (pdf) \(f(x)\) is continuous at all but a finite number of points and possesses the following properties.

Non-negative

\(f(x) \geq 0\) for all \(x\)

Total area = 1

\(\displaystyle\int_{-\infty}^{\infty} f(x)\,dx = 1\)

Probability = area under the curve

\(\displaystyle P(a < X \leq b) = \int_a^b f(x)\,dx\)

⚠️ Single Points Have Zero Probability

Because the area over a single point is zero, \(P(X = c) = 0\) for any value \(c\). This means \(<\) and \(\leq\) give the same answer: \(P(a < X < b) = P(a \leq X \leq b)\). It also means \(f(x)\) itself is not a probability — it is a density, and it can be bigger than 1.

"Show that f(x) is a pdf" — the checklist

You must show both properties: (1) \(f(x) \geq 0\) across the whole given range, and (2) \(\int f(x)\,dx = 1\) over that range. Forgetting the first one loses marks. Outside the stated range, \(f(x) = 0\).

Example 01

📝 Example 01

Show that \(f(x)\) is a probability density function where

\[f(x) = \tfrac{1}{2}(x - 3) \qquad \text{for } 3 \leq x \leq 5.\]

Find \(P(X < 4)\).

Show solution
Property 1: non-negative

For \(3 \leq x \leq 5\), we have \(x - 3 \geq 0\), so \(f(x) = \tfrac{1}{2}(x-3) \geq 0\). ✓

Property 2: total area is 1
\[\int_3^5 \tfrac{1}{2}(x-3)\,dx = \tfrac{1}{2}\left[\frac{(x-3)^2}{2}\right]_3^5 = \tfrac{1}{2}\left(\frac{4}{2} - 0\right) = 1 \;✓\]

Both properties hold, so \(f(x)\) is a pdf.

Find P(X < 4)
\[P(X < 4) = \int_3^4 \tfrac{1}{2}(x-3)\,dx = \tfrac{1}{2}\left[\frac{(x-3)^2}{2}\right]_3^4 = \tfrac{1}{2}\cdot\tfrac{1}{2} = \tfrac{1}{4}\] f(x) is a valid pdf · P(X < 4) = 1/4 = 0.25

Example 02 — Finding an Unknown Constant

📝 Example 02
\[f(x) = k(9 - x^2) \qquad \text{for } -3 \leq x \leq 3\]
  • (a) Find the value of \(k\) and calculate \(P(-1 < X < 2)\)
  • (b) Find \(P(X = 2)\)
Show solution
(a) Find k — set the total area equal to 1
\[\int_{-3}^{3} k(9 - x^2)\,dx = k\left[9x - \frac{x^3}{3}\right]_{-3}^{3} = k\big[(27 - 9) - (-27 + 9)\big] = 36k\] \[36k = 1 \quad\Longrightarrow\quad k = \frac{1}{36}\]
(a) Find P(−1 < X < 2)
\[P(-1 < X < 2) = \frac{1}{36}\left[9x - \frac{x^3}{3}\right]_{-1}^{2} = \frac{1}{36}\left[\left(18 - \frac{8}{3}\right) - \left(-9 + \frac{1}{3}\right)\right]\] \[= \frac{1}{36}\left[\frac{46}{3} + \frac{26}{3}\right] = \frac{1}{36} \times 24 = \frac{2}{3}\]
(b) Find P(X = 2)

For a continuous random variable the probability of any single exact value is zero — there is no area over a single point:

\[P(X = 2) = \int_2^2 f(x)\,dx = 0\] k = 1/36 · P(−1 < X < 2) = 2/3 ≈ 0.667 · P(X = 2) = 0

3. Mean and Variance of a Continuous Random Variable

Mean (Expected Value)
\[E(x) = \mu = \int_{-\infty}^{\infty} x\,f(x)\,dx\]
Variance
\[\text{var}(x) = \sigma^2 = \int_{-\infty}^{\infty} x^2 f(x)\,dx - \big[E(x)\big]^2\]

In practice you only integrate over the range where \(f(x)\) is non-zero, because \(f(x) = 0\) everywhere else.

Discrete (Unit 07)Continuous (Unit 09)
Mean\(\sum x\,p(x)\)\(\int x\,f(x)\,dx\)
\(E(X^2)\)\(\sum x^2 p(x)\)\(\int x^2 f(x)\,dx\)
Variance\(E(X^2) - [E(X)]^2\)\(E(X^2) - [E(X)]^2\)
💡 Symmetry Shortcut

If \(f(x)\) is symmetric about some value \(c\) — for example an even function on a range centred at 0 — then \(E(X) = c\) immediately, with no integration needed. You still need to integrate for the variance.

Example 03

📝 Example 03

The continuous random variable \(X\) has probability density function

\[f(x) = \frac{1}{36}(9 - x^2) \qquad \text{for } -3 \leq x \leq 3.\]

(a) Find the mean and variance of \(X\).

Show solution
Mean
\[E(X) = \int_{-3}^{3} x \cdot \frac{1}{36}(9 - x^2)\,dx = \frac{1}{36}\left[\frac{9x^2}{2} - \frac{x^4}{4}\right]_{-3}^{3} = \frac{1}{36}(0) = 0\]

This matches the symmetry shortcut: \(9 - x^2\) is symmetric about \(x = 0\), so the mean must be 0.

E(X²)
\[E(X^2) = \frac{1}{36}\int_{-3}^{3}(9x^2 - x^4)\,dx = \frac{1}{36}\left[3x^3 - \frac{x^5}{5}\right]_{-3}^{3}\] \[= \frac{1}{36}\times 2\left(81 - \frac{243}{5}\right) = \frac{1}{36}\times\frac{324}{5} = \frac{9}{5}\]
Variance
\[\text{Var}(X) = E(X^2) - [E(X)]^2 = \frac{9}{5} - 0^2 = \frac{9}{5}\] Mean = 0 · Variance = 9/5 = 1.8

4. Mode and Median of a Continuous Random Variable

Mode

Mode: The mode is the value \(x\) at which the pdf reaches its maximum.
Finding the Mode
\[f(x) \text{ is maximum at } x = \text{mode} \qquad\text{or where}\qquad f'(x) = 0\]
⚠️ Check It's a Maximum

\(f'(x) = 0\) also finds minimums. Confirm with \(f''(x) < 0\), and check the endpoints of the range too — if \(f(x)\) is a straight line (like Example 01), the maximum is at an endpoint and \(f'(x)\) is never zero.

Median

Median: The median \(m\) of a continuous random variable having pdf \(f(x)\) is the value that splits the area under the curve exactly in half.
Median
\[P(X \leq m) = P(X \geq m) = 0.5\] \[\int_{-\infty}^{m} f(x)\,dx = \int_{m}^{\infty} f(x)\,dx = 0.5\]

Integrate from the start of the range up to \(m\), set it equal to 0.5, and solve for \(m\). This usually gives a quadratic — keep only the root that lies inside the range.

Quartiles Work the Same Way

The lower quartile \(Q_1\) solves \(\int_{-\infty}^{Q_1} f(x)\,dx = 0.25\), and the upper quartile \(Q_3\) solves the same equation with 0.75. Then \(IQR = Q_3 - Q_1\), just as in Unit 04.

5. Cumulative Distribution Function (cdf)

Definition: The Cumulative Distribution Function (CDF) gives the probability that a random variable takes on a value less than or equal to a specified value.
CDF
\[F(a) = P(X \leq a)\] \[F(x) = \int_{-\infty}^{x} f(t)\,dt\]

\(F(x)\) is the cdf corresponding to the pdf \(f(x)\). The two are linked both ways:

pdf ↔ cdf
\[F(x) = \int f(x)\,dx \qquad\qquad f(x) = F'(x)\]

Writing a cdf Properly

For a pdf that is non-zero only on \(a \leq x \leq b\), a complete cdf has three pieces:

\[F(x) = \begin{cases} 0, & x < a \\[4pt] \displaystyle\int_a^x f(t)\,dt, & a \leq x \leq b \\[4pt] 1, & x > b \end{cases}\]
✅ Self-check

Your middle piece must give \(F(a) = 0\) and \(F(b) = 1\). If it doesn't, you've lost a constant of integration — always integrate from \(a\) to \(x\) rather than writing an indefinite integral.

💡 The cdf Makes Everything Faster

Once you have \(F(x)\): \(P(X \leq c) = F(c)\), \(P(c < X \leq d) = F(d) - F(c)\), and the median solves \(F(m) = 0.5\). One integration, then just substitution.

6. Full Example — Weekly Petrol Consumption

📝 Example

The weekly petrol consumption, in hundreds of litres, of a sales representative may be modelled by the random variable \(X\) with probability density function

\[f(x) = a\,x(4 - 3x) \qquad \text{for } 0 \leq x \leq \tfrac{4}{3}.\]
  • (i) Find the value of \(a\)
  • (ii) Find the mean of the weekly consumption
  • (iii) Find the probability that the weekly consumption will be less than 1 hundred litres
  • (iv) Find the mode of the weekly consumption
  • (v) Construct the corresponding cdf for the above pdf
Show solution

Expand first: \(f(x) = a(4x - 3x^2)\).

(i) Find a — total area = 1
\[\int_0^{4/3} a(4x - 3x^2)\,dx = a\Big[2x^2 - x^3\Big]_0^{4/3} = a\left(\frac{32}{9} - \frac{64}{27}\right) = a\left(\frac{96 - 64}{27}\right) = \frac{32a}{27}\] \[\frac{32a}{27} = 1 \quad\Longrightarrow\quad a = \frac{27}{32}\]
(ii) Mean
\[E(X) = \frac{27}{32}\int_0^{4/3}(4x^2 - 3x^3)\,dx = \frac{27}{32}\left[\frac{4x^3}{3} - \frac{3x^4}{4}\right]_0^{4/3}\] \[= \frac{27}{32}\left(\frac{256}{81} - \frac{192}{81}\right) = \frac{27}{32}\times\frac{64}{81} = \frac{2}{3}\]

So the mean weekly consumption is \(\tfrac{2}{3}\) hundred litres \(\approx 66.7\) litres.

(iii) P(X < 1)
\[P(X < 1) = \frac{27}{32}\Big[2x^2 - x^3\Big]_0^{1} = \frac{27}{32}(2 - 1) = \frac{27}{32}\]
(iv) Mode — differentiate and set to zero
\[f'(x) = \frac{27}{32}(4 - 6x) = 0 \quad\Longrightarrow\quad x = \frac{2}{3}\]

\(f''(x) = \frac{27}{32}(-6) < 0\), so this is a maximum. Mode \(= \tfrac{2}{3}\) hundred litres.

Notice mean = mode = \(\tfrac{2}{3}\). That's no coincidence: \(x(4-3x)\) is a parabola symmetric about \(x = \tfrac{2}{3}\), the midpoint of the range \([0, \tfrac{4}{3}]\).

(v) The cdf
\[F(x) = \int_0^{x}\frac{27}{32}(4t - 3t^2)\,dt = \frac{27}{32}(2x^2 - x^3)\] \[F(x) = \begin{cases} 0, & x < 0 \\[4pt] \dfrac{27}{32}(2x^2 - x^3), & 0 \leq x \leq \tfrac{4}{3} \\[4pt] 1, & x > \tfrac{4}{3} \end{cases}\]

Check: \(F(0) = 0\) and \(F(\tfrac{4}{3}) = \frac{27}{32}\times\frac{32}{27} = 1\). ✓  Also \(F(1) = \frac{27}{32}\), which matches part (iii).

a = 27/32 · mean = 2/3 (≈ 66.7 L) · P(X < 1) = 27/32 ≈ 0.844 · mode = 2/3
